# v0.2 Methodology and Decisions

The v0.2 baseline deliberately uses no external services. Keyword count and BM25 retain the original lexical approaches. The vector slot is now a deterministic TF-IDF cosine baseline; historical dense `embeddinggemma` experiments remain preserved but cannot be the CI baseline because they require local model state. Hybrid retrieval uses reciprocal-rank fusion so unlike score ranges are not mixed directly.

Fifty questions were defensible because the committed source contains 73 substantial chunks spanning all five books. Thirty development questions cover early and middle arguments; twenty held-out questions emphasize providence, fortune, foreknowledge, eternity, and free will. Every question points to exact committed evidence. These labels were manually checked against source passages but have not received independent scholarly adjudication.

The old ten-question Markdown evaluation and historical reports are retained as project history. New generated files cannot overwrite them. The CLI defaults to the development split, requiring explicit `--split test` for held-out evaluation.

Grounded-answer evaluation is a deterministic regression layer over curated fixtures. Citation membership, unsupported-claim annotations, answerability, and refusal checks are transparent heuristics. An LLM judge is intentionally deferred until its prompts, model identity, sampling parameters, and raw judgments can be versioned without weakening the offline path.
